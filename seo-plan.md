# SEO Plan — Noelia Makeup

## 1. Overview

- **Client:** Noelia (Noe) — Noelia Makeup
- **Industry:** Professional Makeup Artistry (Bridal, Editorial, Special Occasions)
- **Location:** Australia (TBC — exact city needed)
- **Website:** TBD (current Next.js site under development)

---

## 2. Goals

- Increase organic visibility for makeup artist services in the local area
- Rank for high-intent local keywords (e.g., "makeup artist [city]", "bridal makeup [city]")
- Drive enquiries/bookings through the website
- Build brand authority and online presence

---

## 3. Phase 1 — Foundation (Month 1–2)

### 3.1 Technical SEO

- [ ] Set up proper meta titles and descriptions for all pages
- [ ] Implement Open Graph and Twitter Card meta tags
- [ ] Add structured data (LocalBusiness, Person, Service schema)
- [ ] Create and submit XML sitemap to Google Search Console
- [ ] Set up Google Search Console and Google Analytics 4
- [ ] Ensure mobile responsiveness and Core Web Vitals pass
- [ ] Optimise image alt tags and file sizes (WebP format)
- [ ] Implement canonical URLs
- [ ] Add robots.txt configuration
- [ ] Ensure proper heading hierarchy (H1, H2, H3)

### 3.2 Google Business Profile

- [ ] Create or claim Google Business Profile
- [ ] Complete all business information (address, phone, hours, categories)
- [ ] Add high-quality portfolio photos
- [ ] Set up services and service areas
- [ ] Request initial reviews from past clients

### 3.3 Keyword Research

Target keyword clusters:

| Cluster | Example Keywords |
|---------|-----------------|
| Bridal | bridal makeup artist [city], wedding makeup [city], bridal hair and makeup [city] |
| General | makeup artist [city], professional makeup artist near me, MUA [city] |
| Editorial/Creative | editorial makeup artist [city], creative makeup artist, fashion makeup artist |
| Occasion | special occasion makeup [city], event makeup artist, formal makeup [city] |
| Cultural | Latin-inspired makeup, South American makeup artist |

---

## 4. Phase 2 — On-Page SEO & Content (Month 2–3)

### 4.1 Page Optimisation

- **Homepage:** Target primary keyword (e.g., "Professional Makeup Artist [City]")
- **About Page:** Build E-E-A-T (Experience, Expertise, Authoritativeness, Trust) — highlight 10 years of experience, psychology background, international training
- **Services Page:** Individual sections or pages for each service (bridal, editorial, special occasion, etc.)
- **Contact Page:** Include NAP (Name, Address, Phone) consistently
- **Portfolio/Gallery:** Optimise images with descriptive alt text and captions

### 4.2 Content Strategy

- [ ] Create a blog section for ongoing content
- [ ] Publish 2–4 blog posts per month covering:
  - Makeup tips and tutorials
  - Behind-the-scenes from shoots/weddings
  - Seasonal makeup trends
  - Product recommendations
  - Client transformation stories (with permission)
- [ ] Create dedicated landing pages for key services

### 4.3 Internal Linking

- [ ] Link between related services and blog posts
- [ ] Add breadcrumb navigation
- [ ] Ensure all important pages are within 3 clicks of homepage

---

## 5. Phase 3 — Off-Page SEO & Local (Month 3–6)

### 5.1 Local SEO

- [ ] Submit to local business directories (Yellow Pages, True Local, etc.)
- [ ] List on makeup/wedding-specific directories (Easy Weddings, WedShed, Style Me Pretty, etc.)
- [ ] Ensure consistent NAP across all directories
- [ ] Build location-specific content

### 5.2 Link Building

- [ ] Collaborate with local wedding vendors for cross-linking
- [ ] Guest post on beauty/wedding blogs
- [ ] Get featured in local publications or online magazines
- [ ] Leverage social media profiles for backlinks (Instagram, TikTok, YouTube, Facebook)

### 5.3 Reviews Strategy

- [ ] Set up a system to request Google reviews after each booking
- [ ] Respond to all reviews promptly
- [ ] Showcase testimonials on the website

---

## 6. Phase 4 — Ongoing Optimisation (Month 6+)

- [ ] Monthly keyword ranking tracking
- [ ] Quarterly content audit and refresh
- [ ] Monitor and improve Core Web Vitals
- [ ] Analyse Google Analytics for user behaviour insights
- [ ] A/B test meta titles and descriptions for CTR improvement
- [ ] Expand keyword targeting based on performance data
- [ ] Continue building backlinks and local citations
